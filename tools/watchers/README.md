# Watcher Scripts

Console watcher scripts used to capture real-time DOM changes and identify stable selectors for AI chat adapters.

## Files
- `deepseek-watcher.js`: DeepSeek DOM watcher.
- `doubao-watcher.js`: Doubao DOM watcher.
- `yuanbao-watcher.js`: Yuanbao DOM watcher.

## Usage
1. Open target chat page.
2. Paste script content into DevTools Console before sending a prompt.
3. Send a prompt and wait for completion.
4. Copy candidate selector logs and refine `adapters.js`.
